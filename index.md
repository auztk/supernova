# Supernova

A Minecraft: Java Edition launcher with mod support, a built-in client mod and encrypted logins.

**Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.**

## Download

[Get the latest Windows build]({{ site.github.repository_url }}/releases/latest)

Each release lists a SHA-256 checksum. Check your download against it before you run it:

    certutil -hashfile Supernova-windows.zip SHA256

Supernova is free and has no telemetry, analytics or ads. It talks only to Microsoft, Mojang, Fabric and Modrinth.
